# Z-Cards
Z-Cards is an academic project that aims to simulate an e-commerce service for Dragon Ball trading card packs. The project is currently under development, with further changes expected; this repository is provided to demonstrate the progress made on the project.

Z-Cards es un proyecto académico el cual trata de simular un servicio de e-commerce de sobres de cartas de Dragon Ball, este proyecto sigue en desarrollo hasta el momento y se esperan cambios a futuro y este repositorio se sube con fines de demostrar avance en el proyecto
